# Process journal

Record of how your process is being built: what you asked for, what was done, what went wrong and what you learned. It is the basis for the next similar project. The decisions themselves are in [`decisions.md`](decisions.md); the history is here.

Format: one entry per step, in order. Each entry answers **request → done → problems → lesson**. The number is always the file's last + 1.

Template:

```
## YYYY-MM-DD · N. Short title

- **Request:** what was wanted.
- **Done:** what was done, with the files.
- **Problems:** what went wrong (including Claude's mistakes).
- **Lesson:** what stays for next time.
```
