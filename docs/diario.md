# Diário do processo

Registro de como o seu processo vai sendo construído: o que você pediu, o que foi feito, o que deu errado e o que aprendeu. Serve de base para o próximo projeto parecido. As decisões em si ficam em [`decisoes.md`](decisoes.md); aqui fica a história.

Formato: uma entrada por etapa, em ordem. Cada entrada responde **pedido → feito → problemas → lição**. O número é sempre o último do arquivo + 1.

Modelo:

```
## AAAA-MM-DD · N. Título curto

- **Pedido:** o que se queria.
- **Feito:** o que foi feito, com os arquivos.
- **Problemas:** o que deu errado (inclusive os erros do Claude).
- **Lição:** o que fica para a próxima vez.
```
